# BMW Home (launcher para JUNSUN 8667Q, Android 10, 1280x720)

1. Sube esta carpeta a un repositorio de GitHub (pestaña Actions compila el APK).
2. Descarga el artifact BmwLauncher-APK y copia app-debug.apk a la radio.
3. Instálalo (activa orígenes desconocidos) y elige BMW Home como launcher de Inicio.
